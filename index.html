So löst du den Code ein

  1. 01

    Einkauf zusammenstellen. Lebensmittel im Wert von mindestens 30 € in den Flink-Warenkorb legen (Tabak und Pfand zählen nicht mit).

  2. 02

    Zur Kasse gehen. Im Bereich „Zahlungen" auf „Gutscheincode hinzufügen" tippen.

  3. 03

    Code eingeben. FLINK-MPDEUA eintippen und bestätigen.

  4. 04

    Bestellen. Die 15 € werden automatisch von der Summe abgezogen, sobald der Code gültig ist.

Häufige Fragen

Gilt der Code auch außerhalb von Frankfurt?

Ja, überall dort, wo die Flink-App vor Ort liefert — Frankfurt am Main eingeschlossen, plus weitere an Flink angebundene Städte.

Was passiert, wenn der Bestellwert unter 30 € liegt?

Die App zieht den Rabatt erst ab, sobald der anrechenbare Bestellwert (ohne Tabak und Pfand) mindestens 30 € erreicht.

Ist der Code irgendwann aufgebraucht?

Ja. Laut Flink ist FLINK-MPDEUA insgesamt maximal 50-mal einlösbar, danach lehnt die App den Code ab.

Unabhängig geteilter Gutscheincode, kein offizielles Angebot der Flink SE. Es gelten die aktuellen Konditionen und AGB von Flink zum Zeitpunkt der Einlösung.
